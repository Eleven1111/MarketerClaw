## 为什么 mc-brand 是最上游的技能

```
mc-brand（我们是谁）
  ↓
mc-storyteller（我们怎么讲故事）
  ↓
mc-insight（文化环境告诉我们什么值得讲）
  ↓
mc-campaign / mc-content / mc-aigc / mc-kol ...（执行层）
```

没有 brand.md，其他所有技能都在猜"这个品牌应该用什么语气说话"。有了 brand.md，所有下游技能自动对齐。

## 工作方式

1. 确认品牌策略范围：
   - **起点**：从零创建品牌 / 已有品牌需要梳理 / 品牌焕新升级
   - **输入**：创始人理念、产品特性、目标市场、竞品格局
   - **深度**：核心定位（快速版）/ 完整品牌圣经
2. 读取 `brief.md`、`research.md`、`insight.md`、`compete.md`（如存在）作为输入
3. **按需加载参考**：仅当涉及**多产品线扩张、孵化副牌/低价引流线、B2B 供应链/工厂转 C 端品牌、自研成分/工艺独立命名（要素品牌）、或跨界联名/渠道专供款**时，读取 `references/brand-architecture-matrix.md`（含购买三层级、双向溢出五关决策树、11 种次级关系谱系与多主体传播秩序隔离表）；单一 SKU 初创冷启动阶段直接跳过，避免上下文膨胀
4. **核心产出写入 `campaigns/{project-slug}/brand.md`** — 这个文件是全局品牌上下文，其他所有技能会读取它

## 模块 1：品牌本质（Brand Essence）

品牌本质是一切品牌决策的原点——一个品牌存在的根本理由。

### 品牌本质金字塔

```
                    ┌─────────┐
                    │ 品牌使命  │  ← 我们为什么存在
                    │ Purpose  │
                    ├─────────┤
                 ┌──│ 品牌愿景  │──┐  ← 我们想创造什么世界
                 │  │ Vision   │  │
                 ├──┼─────────┼──┤
              ┌──│  │ 品牌价值观 │  │──┐  ← 我们相信什么
              │  │  │ Values   │  │  │
              ├──┼──┼─────────┼──┼──┤
           ┌──│  │  │ 品牌承诺  │  │  │──┐  ← 我们对用户的核心承诺
           │  │  │  │ Promise  │  │  │  │
           └──┴──┴──┴─────────┴──┴──┴──┘
```

```markdown
## 品牌本质

### 品牌使命（Purpose）
{一句话：这个品牌存在是为了什么}

WHY — 创始人为什么要做这件事（不是"赚钱"，是内心的那个驱动力）
{创始人故事/初心的一句话提炼}

### 品牌愿景（Vision）
{如果这个品牌成功了，世界会有什么不同？}

### 品牌价值观（Values）
不是挂在墙上的标语，而是真正影响日常决策的原则。

| 价值观 | 含义 | 在实际决策中意味着什么 |
|--------|------|---------------------|
| {价值观 1} | {解释} | {遇到 XX 情况时，我们选择 XX 而不是 XX} |
| {价值观 2} | | |
| {价值观 3} | | |

测试标准：如果一个价值观不能帮你做出一个困难的取舍，它就是空话。

### 品牌承诺（Promise）
{用户选择我们而不是竞品，我们承诺给他/她什么}
- 功能性承诺：{产品层面}
- 情感性承诺：{感受层面}
- 社会性承诺：{身份/群体层面，如适用}
```

### 资产光谱自下而上提炼通道（专治白牌出海 / 供应链与技术团队定位悬空）

当团队有扎实货盘、工厂或专研技术，却说不出宏大的品牌使命时，**禁止硬编空洞的公益/情怀口号**，改走「五阶资产光谱」自下而上反推——让最顶层的主张天然自带可核实的 RTB 支撑：

```
第 1 阶：独占资产（We Own）     → 我们掌握什么稀缺产地、供应链产线、专利库或临床/实测样本？
  ↓
第 2 阶：具体交付（We Deliver） → 基于这项资产，我们稳定交付哪一类高标准产品或服务？
  ↓
第 3 阶：核心工艺（We Apply）   → 中间用了什么别人抄不走的配方、结构公差或质检标准？
  ↓
第 4 阶：角色身份（Who We Are） → 长期坚持这套做法，我们在用户眼里是什么角色（如严苛的参数死磕者）？
  ↓
第 5 阶：使命主张（We Believe） → 这个角色最看不惯行业里什么乱象、最捍卫用户的什么权利？（即真使命）
```

> 校验标准：第 5 阶写出的使命必须能一路倒推回第 1–3 阶的物理/技术事实；倒推不回去的句子一律判为悬空口号，退回重写。

## 模块 2：品牌定位（Brand Positioning）

定位不是"我们想成为什么"，是"在用户心智中，我们占据哪个唯一的位置"。

### 定位公式

```
对于 {目标用户}，
{品牌名} 是 {品类/赛道} 中
唯一一个 {差异化核心} 的品牌，
因为 {支撑理由 / RTB}。
```

### 「唯一」检验（定位写完必须过这一关）

公式里写着"唯一一个"，但绝大多数定位陈述填完之后，把品牌名换成竞品名照样成立——那句话就不是定位，是品类描述。**定位陈述初稿完成后，逐条过下面四关，任何一关不过就回到公式重写，不要带着不合格的定位往下走**（后面的人格、语调、叙事全都建立在它上面，错了是整条链返工）。

| 检验 | 做法 | 不通过的表现 |
|------|------|-------------|
| **替换测试**（核心） | 把定位陈述里的品牌名换成最强的 2-3 个竞品名，逐句念出来 | 换成竞品后句子依然成立且没人会反对 → 说的是品类共性，不是你的位置 |
| **反面测试** | 问："有没有正经品牌会主动选择相反的位置？" | 反面荒谬（如"我们提供劣质服务"）→ 这不是取舍，是正确的废话。真定位必然意味着放弃了某些用户或某些好处 |
| **落地测试** | 问："这个差异化核心，用户在哪个具体触点上能感知到？" | 说不出具体触点（包装/首屏/客服话术/产品体验中的哪一处）→ 只是内部口号 |
| **RTB 测试** | 检查支撑理由是不是可被第三方核实的事实 | RTB 是"我们更用心""品质更好"这类无法证伪的形容 → 需要换成配方、工艺、供应链、资质、数据等可验证事实 |

**检验结果必须写进产出**，不是内部动作：

```markdown
### 「唯一」检验
- 替换测试：换成 {竞品A}/{竞品B} 后 → {是否仍然成立，哪一句最先失效}
- 反面测试：相反位置是 {描述} → {有/无}正经品牌会选，说明本定位{有/无}真实取舍
- 落地测试：用户在 {具体触点} 能感知到差异
- RTB 可核实性：{RTB 内容} → {可核实的事实依据}
- 结论：通过 / 需重写（原因：{...}）
```

未通过的定位不要写进 brand.md 就往下游传——mc-storyteller、mc-copy、mc-content 都会把它当成既定前提展开，一句"我们更懂年轻人"这种伪定位会被放大成整套物料。

### 定位地图

```markdown
## 品牌定位

### 定位陈述
{完整定位公式}

### 竞争参照框架
| 维度 | 我们 | 竞品 A | 竞品 B | 竞品 C |
|------|------|--------|--------|--------|
| 核心卖点 | | | | |
| 价格带 | | | | |
| 目标人群 | | | | |
| 品牌调性 | | | | |
| 渠道重心 | | | | |

### 定位选择的逻辑
- 为什么选这个位置（而不是其他）：{空白大 / 能力匹配 / 文化趋势支撑}
- 这个位置的风险：{可能被挑战的地方}
- 防御策略：{如何巩固这个位置}

### 品类入口词
当用户想到 {什么场景/需求} 时，第一个想到我们。
- 主入口：{核心关联场景}
- 副入口：{次要关联场景}
```

### 「心智灯塔人群 × 商业扩展人群」双层锚定与「主驱动二选一铁律」

1. **双层人群防破圈稀释**：既不能把人群缩得太窄导致盘子见顶，也不能为了讨好所有人把调性做成白开水——在 `brand.md` 中拆开两层定义：
   - **心智灯塔人群（10%–20% 高势能核心客）**：对该品类最挑剔、审美或专业度最高、有主动造梗/安利能力的种子人群。**品牌的视觉调性、语调姿态与首发阵地 100% 锚定他们，绝不为了迁就大众而向下妥协审美。**
   - **商业扩展人群（80% 泛需求跟随客）**：向往灯塔人群的生活方式或信服其专业背书的普通买家。**产品易用性、规格梯度、电商长尾搜索词与基础客服说明向他们敞开，降低购买与使用门槛。**
2. **功能驱动 vs 情感驱动「主次二选一」铁律**：同一品牌在首屏 3 秒内**必须明确唯一主驱动力**——要么以**功能硬利益**为主钩子（情感共鸣做加分项），要么以**情感/身份认同**为主钩子（客观参数做兜底信任状）；禁止两者五五开平铺导致首屏失焦。

## 模块 3：品牌人格（Brand Personality）

如果品牌是一个人，TA 是谁？

### 人格原型

从 12 种经典品牌原型中选择最匹配的 1-2 个：

| 原型 | 核心动机 | 品牌例子 | 适合品类 |
|------|---------|---------|---------|
| 天真者 (Innocent) | 追求简单、纯粹、幸福 | 可口可乐、多芬 | 食品/个护/儿童 |
| 探索者 (Explorer) | 自由、发现、突破边界 | North Face、Jeep | 户外/旅行/科技 |
| 智者 (Sage) | 知识、真理、洞察 | Google、BBC | 教育/科技/咨询 |
| 英雄 (Hero) | 勇气、掌控、证明自己 | Nike、Under Armour | 运动/健康/工具 |
| 叛逆者 (Outlaw) | 打破规则、颠覆传统 | Harley-Davidson、Diesel | 潮流/科技/亚文化 |
| 魔法师 (Magician) | 转化、创造奇迹 | Apple、Dyson | 科技/美妆/高端 |
| 普通人 (Everyman) | 归属感、真实、接地气 | IKEA、优衣库 | 大众消费品 |
| 情人 (Lover) | 亲密、美感、愉悦感官 | Chanel、Godiva | 奢品/美妆/食品 |
| 小丑 (Jester) | 快乐、幽默、享受当下 | M&M's、老干妈 | 食品/娱乐/年轻品牌 |
| 照顾者 (Caregiver) | 保护、关怀、利他 | Johnson's、Volvo | 母婴/健康/保险 |
| 创造者 (Creator) | 创新、表达、做出好东西 | Lego、Adobe | 创意工具/DIY/教育 |
| 统治者 (Ruler) | 权力、秩序、品质标杆 | Rolex、Mercedes | 高端/金融/商务 |

```markdown
## 品牌人格

### 主原型：{原型名}
为什么选它：{与品牌使命和用户期望的连接}

### 辅原型：{原型名}（可选）
加入辅原型的目的：{补充主原型缺少的维度}

### "如果品牌是一个人"
- 年龄感：{不是目标用户年龄，是品牌自身的"年龄感"}
- 穿着风格：{视觉隐喻}
- 说话方式：{直接/含蓄/幽默/严肃/温暖/酷}
- 社交场景中的角色：{领导者/好朋友/导师/同行者/守护者}
- 让人觉得：{用户和这个品牌在一起时的感受}

### 人格边界
- 我们是：{3-5 个形容词}
- 我们不是：{3-5 个要回避的形容词}
- 我们绝不：{底线行为}
```

### 主辅原型双轴相容性校验与「人格过载黑化防线」

1. **双轴相容性校验**：12 原型分布在「外向释放 ↔ 内敛克制」与「群体联结 ↔ 个体掌控」两条张力轴上。主原型与辅原型原则上选**同象限或相邻象限**；**禁止在未做触点隔离的前提下强行混搭对角线反义原型**（如「统治者 + 小丑」「照顾者 + 叛逆者」），否则公域玩梗与详情页立威精神分裂，用户无法建立稳定预期。
2. **四象限人格过载黑化防线（Overdose Guardrail）**：AI 批量写稿或社媒运营用力过猛时，品牌人格极易滑向令人反感的“黑化态”。`brand.md` 必须写明本品牌所属象限的过载禁区，并交由 `mc-review` 审校拦截：

| 人格象限（代表原型） | 正常高光态 | ❌ 过载黑化态（触发即拦截重写） | 纠偏护栏 |
|---------------------|-----------|--------------------------------|---------|
| **外向 × 掌控**（英雄 / 叛逆者 / 统治者） | 笃定敢言、有骨气、行业立规 | **爹味说教、居高临下教育用户、拉踩同行傲慢自嗨** | 把锋芒对准行业旧痛点，对真实用户始终保持平视尊重 |
| **外向 × 联结**（小丑 / 情人 / 探索者） | 鲜活松弛、懂梗有趣、有感染力 | **硬蹭低俗烂梗、油腻讨好亢奋、不合时宜抖机灵** | 幽默只用来自嘲或化解尴尬，涉及品质售后与严肃议题立即收起玩梗 |
| **内敛 × 掌控**（智者 / 魔法师 / 创造者） | 专业克制、审美在线、逻辑自洽 | **冰冷参数堆砌、掉书袋端架子、讲没人听得懂的黑话** | 每个专业概念必须翻译成用户日常可感知的体感变化 |
| **内敛 × 联结**（照顾者 / 普通人 / 天真者） | 温和可靠、真诚体贴、无距离感 | **卑微客服腔（“亲亲跪求支持”）、温吞老好人、毫无记忆点** | 温柔不等于没立场，在原料底线与用户权益问题上态度鲜明 |

## 模块 4：品牌语调体系（Tone of Voice）

语调不是"写文案用什么词"，是品牌在所有触点上说话的方式。

### 语调维度

```markdown
## 品牌语调体系

### 语调四维定位
| 维度 | 我们的位置 | 说明 |
|------|----------|------|
| 正式 ←→ 随意 | {如：偏随意，6/10} | {什么时候更正式，什么时候更随意} |
| 严肃 ←→ 幽默 | {如：中间偏幽默，7/10} | {哪些场景可以幽默，哪些不行} |
| 尊重 ←→ 不敬 | {如：尊重但不卑微，3/10} | {对用户平视，不跪舔也不居高} |
| 热情 ←→ 克制 | {如：温暖但不过度，4/10} | {表达关心但不煽情} |

### 语言偏好
- **常用词**：{品牌常用的词汇集合}
- **避免词**：{品牌绝不用的词}
- **句式偏好**：{短句干脆 / 长句有节奏 / 口语化 / 文艺感}
- **表情符号**：{用/不用，如果用，偏好哪些}
- **中英混用**：{是否允许，在什么场景}

### 不同场景的语调调整

| 场景 | 语调微调 | 示例 |
|------|---------|------|
| 产品描述 | {更专业，聚焦功能价值} | |
| 社媒日常 | {更轻松，像朋友聊天} | |
| 客诉回复 | {更温暖，先共情再解决} | |
| 品牌宣言 | {更有力量，简洁有节奏} | |
| 促销活动 | {更直接，但不low} | |
| 危机公关 | {更严肃，诚恳负责} | |

### 语调示例对照

| 场景 | ❌ 不像我们 | ✅ 像我们 |
|------|-----------|----------|
| 欢迎新用户 | | |
| 产品缺货 | | |
| 用户好评 | | |
| 被质疑时 | | |
```

## 模块 5：品牌视觉语言（Visual Identity Direction）

| ✅ 做 | ❌ 不做 |
|-------|--------|
| {品牌视觉风格正面描述} | {品牌视觉风格反面描述} |

### 摄影/影像风格方向
- 光线偏好：{自然光/人工光/柔光/硬光}
- 构图偏好：{留白/紧凑/对称/自然随性}
- 人物呈现：{真实/理想化/场景化/特写}
- 场景偏好：{室内/户外/纯色背景/生活场景}

### 字体/排版方向

### 动态母体视觉架构：30% 不变量识别骨架 × 70% 可变量延展槽位

静态 VI 手册在多 SKU 矩阵与高频社媒投放中极易陷入两极死胡同——要么死守一套模板导致审美疲劳，要么每换一个节点/口味就彻底跑偏像换了个牌子。输出视觉方向时，必须同步拆清**不变量骨架**与**可变量槽位**，供 `mc-aigc` 直接映射进 `style.json`：

- **30% 不变量识别骨架（跨全线/全年锁死，对应 `style_fidelity_anchors`）**：标志性构图留白比例、核心几何容器/边框轮廓、主光影质地（如清透晨光漫反射 / 高反差硬光金属）、品牌底色锚点——确保**遮住 Logo 也能 1 秒认出是谁**。
- **70% 可变量延展槽位（按 SKU / 平台 / 节点开放，对应 `variable_slots`）**：口味/功效分线辅色、当季场景道具、模特姿态互动、平台画幅裁切比例。

| 系列化视觉编码法（6 选 1–2） | 锁死什么（不变量） | 放开什么（可变量） | 典型适用场景 |
|-----------------------------|-------------------|-------------------|-------------|
| **1. 色相分线法** | 版式构图、字体层级、主容器器型 | 随功效/口味切换高辨识度专属色块 | 多功效护肤、多口味饮品零食 |

| **3. 母体骨架局部变异法** | 核心超级符号/IP 剪影结构 | 局部材质贴图（毛绒/金属/冰晶）与微动作 | 潮玩、数码配件、年轻化大促延展 |

## 模块 6：品牌架构（Brand Architecture）

当品牌不止一个产品线、拟推低价跑量款、或从 B2B 供应链切入 C 端时，需要回答“它们之间怎么排兵布阵且互不反噬”。（完整五关决策树、11 种次级关系谱系与多主体传播秩序隔离表见 `references/brand-architecture-matrix.md`。）

### 核心铁律：购买主界面三层级与「双向溢出 × 比价隔离」

1. **防商标膨胀与搜索词碎片化**：消费者决策界面分为「企业背书层 → 购买主界面层 → 增强型描述词层」。处于单品验证期（L1）至细分品牌期（L2）的团队，针对同人群推出新口味、新规格或相邻步骤款时，**默认采用「主品牌 + 增强型描述词」（如“差旅便携版 / 敏肌特护款”），禁止盲目新建子品牌名**拆散站内外自然搜索词量。
2. **母子双向溢出与全网比价隔离判定**：
   - **低价清仓/拼购跑量副线、高退货试水品** → **强制采用「完全隔离式多品牌」**（独立店名、独立包装、不共享主品牌词），防止全网自动比价抓取直接击穿主品牌价盘与人群标签。
   - **传统供应链/代工大厂孵化高溢价 C 端品牌** → **采用「纯文字弱背书式」**（正面 100% 独立新锐视觉，仅包装背面/底栏小字印出品方资质托底），避免工业厂名劝退高审美客群。
   - **可检测的自研配方 / 独家工艺 / 专利结构** → 评估提炼**要素品牌化（Ingredient Branding）**，将技术命名为独立徽标跨 SKU 复用，把爆品流量沉淀为防跟卖护城河。
3. **合规底线**：要素品牌与跨界联名须具备真实技术依据、有效专利或合法书面授权；禁止虚构海外实验室联合研发，不得伪造集团背景或盗用未授权标识。

### 品牌架构模型速查

| 模型 | 细分落地形态（详见参考矩阵 §3） | 适用场景 | 核心风险防线 |
|------|-------------------------------|---------|-------------|
| 统一品牌 (Branded House) | 同标一统式 / 同标分色分缀式 | 心智集中、人群与价格带同向延展 | 跨入非相关或低质品类会一损俱损 |
| 主副与背书品牌 (Sub-brand / Endorsed) | 主副驱动式 / 图形强背书 / 纯文字弱背书 / 象征印记 | 借母体资质托底切入新细分赛道 | 弱背书禁止正面大字抢戏；强背书须防舆情连坐 |
| 独立多品牌 (House of Brands) | 影子关联式 / 完全隔离式 | 人群审美冲突，或低价防守副牌需防比价击穿 | 完全隔离须连详情页版式与店名一并拆开 |
| 联合品牌 (Co-driver) | 要素品牌化（Ingredient）/ 跨界联名 | 自研成分工艺跨线复用、节点破圈拉新 | 禁止拿普通公模原料造伪黑科技词；联名须锁死授权期 |

```markdown

|------|---------------|------------------------------------------------|---------|---------------------|

```

## 模块 7：品牌试金石（Brand Litmus Test）

一套快速判断"这个决定是否符合品牌"的检查清单。

```markdown
## 品牌试金石

当你不确定一个决策（文案/产品/合作/视觉）是否"品牌"时，过一遍这个清单：

### 5 秒判断
- [ ] 它像我们会做的事吗？
- [ ] 用户看到时，知道这是我们吗（即使没有 logo）？
- [ ] 它让我们的目标用户觉得"这个品牌懂我"吗？

### 深度判断
- [ ] 它符合我们的品牌使命吗？
- [ ] 它的语调在我们定义的范围内（且未滑入人格过载黑化态）吗？
- [ ] 它的视觉守住了 30% 不变量骨架吗？
- [ ] 它不会让我们的用户觉得被冒犯/被俯视/被忽视吗？
- [ ] 如果竞品也做同样的事，我们做出来还有辨识度吗？

### 全链路六大触点调性断层扫描（Touchpoint Consistency Audit）
高调性种草最怕“前戏高级、履约破功”。上线前逐格排查是否存在体验断层：

| 触点环节 | 品牌一致性达标表现 | ❌ 常见破功断层（检出即修） |
|---------|------------------|---------------------------|
| 1. 公域种草钩子 | 视觉与姿态锚定心智灯塔人群，一眼认出母体骨架 | 封面为骗点击用廉价震惊体，与品牌调性割裂 |
| 2. 直播间 / 私域人设 | 主播与社群话术延续品牌人格象限，福利机制体面 | 奢感/专业品牌直播间突然变吼叫式清仓甩卖 |
| 3. 交易详情页 / 落地页 | 首屏唯一主驱动清晰，RTB 证据可核实 | 种草讲克制美学，进店却是五颜六色牛皮癣促销图 |
| 4. 实物开箱与包材触感 | 外箱、内衬、说明卡触感与定价锚点匹配 | 卖高溢价礼赠，到手却是破损薄塑料袋配刺鼻油墨传单 |
| 5. 售后客服与自动回复 | 延续品牌语调温度，遇客诉先给确定性方案 | 机器人冰冷循环话术，或出现卑微跪舔/推诿甩锅 |
| 6. 复购与召回触达 | 在合理消耗周期提供有用提醒或老客专属礼遇 | 下单次日就高频发诱导促销短信骚扰消耗好感 |

> 前置铁律：基础履约与品控门槛（发货时效、尺码/规格准确度、退换响应）未达标前，**禁止用花哨开箱仪式感掩盖产品或履约硬伤**。

### 红线判断
- [ ] 它有没有违反我们"绝不"清单中的任何一条？
- [ ] 它有没有踩到文化雷区（参考 mc-insight 踩雷预警）？
```
