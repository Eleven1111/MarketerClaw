## mc-product 的视角：营销反哺产品

传统流程是产品先做出来，营销再去卖。

mc-product 的逻辑是反过来的：**先回答"这个产品能不能被讲成一个故事"，再决定怎么定义它。**

一个不能被清晰表达的产品，在传播端会浪费巨大的营销预算；
一个有清晰文化锚点的产品，用户会帮你讲故事。

所以造品的起点不是"原料有什么"，而是：

1. 这群人现在有什么没被满足的需求（文化 + 功能的双重需求）
2. 竞品用什么叙事在占领市场，我们的差异化路径是什么
3. 这款产品做出来，用一句话能不能说清楚为什么它值得买

## 工作方式

1. 确认造品范围：
   - **起点**：已有产品想差异化 / 有原料或技术找方向 / 从零定义新品 / 产品线规划
   - **市场**：国内（品类/平台/渠道）/ 出海（目标国家/平台）
   - **品牌约束**：已有品牌调性 / 新品牌从零开始
2. 读取 `brief.md`、`insight.md`、`research.md`、`selection.md`（如存在）作为输入
3. 产出写入 `campaigns/{project-slug}/product.md`
4. **实体消费品按需加载**：仅当产品是实体消费品 / 配饰 / 家居 / 礼品 / 白牌升级时，加载 `references/physical-craft-premium.md`（形色纹图轻改造、公有领域美学转译、开箱辅料、非标产品线角色与退货率前置说明）；SaaS / 数字产品 / 服务类跳过，不加载

## 模块 1：需求空白识别

产品机会藏在"用户有需求但现有产品没有满足好"的夹缝里。

### 需求空白分析框架

**功能性需求空白**
现有产品在功能/效果/便利性上有哪些明显不足？用户差评在集中抱怨什么？

**情感性需求空白**
用户买这类产品时，除了功能，还在追求什么感受？被尊重？有品味感？效率感？仪式感？当下产品的品牌调性是否让他们"觉得自己品味很好"？

**身份认同需求空白**
用这个产品能不能成为"更好的自己"？现有品牌有没有提供这种身份认同锚点？

**场景空白**
哪些使用场景是现有产品根本没有设计进去的？（例：同一品类但适合差旅场景的 SKU 根本没人做）

| 功能性 | | | |
| 情感性 | | | |
| 身份认同 | | | |
| 场景化 | | | |

**最大需求空白：** {一句话，这是后续产品定义的起点}

## 模块 2：产品差异化策略

差异化不是"我们比竞品好一点"，而是找到一个竞品不能轻易复制的位置。

### 差异化路径矩阵

| 差异化路径 | 逻辑 | 适用场景 | 护城河强度 |
|-----------|------|---------|---------|
| **成分/原料差异化** | 独特成分，竞品没有或难以复制 | 护肤/保健/食品 | 中（可被仿制） |
| **效果差异化** | 更快/更强/更精准的效果承诺 | 功能性产品 | 中（需数据支撑） |
| **场景差异化** | 为一个竞品忽视的场景专属设计 | 任意品类 | 中高 |
| **人群差异化** | 专为某个细分人群定制 | 任意品类 | 高（人群粘性强） |
| **体验差异化** | 包装/开箱/使用过程本身就是卖点 | 礼品/高客单/颜值品类 | 中高 |
| **叙事差异化** | 同质化产品，用不同的故事角度重新讲 | 成熟品类突围 | 高（最难被复制） |
| **价格带差异化** | 现有产品集中在中高端，切入亲民段 | 市场分层不完善的品类 | 中 |
| **渠道差异化** | 竞品都在 A 渠道，我们从 B 渠道起来 | 任意品类 | 中（先发优势） |

> 实体消费品想拉开与白牌的搜图比价距离：按 `references/physical-craft-premium.md` §1「形·色·纹·图」四维轻改造矩阵选路径，并遵守 §2 的知识产权边界。

### 品类量化立规（将形容词翻译为可检测公差标准）

在成熟品类中，谁沿用竞品的评价维度，谁就只能陷入同质化内卷；破局的核心是**品类量化立规**——把行业习以为常的模糊品质形容词，强制改写为买家可感知、第三方可检测的物理/工艺/服务量化公差标准，用新立的单项标尺重塑品类对比坐标系：

| 禁用模糊形容词 | 品类量化立规方向 | 立规落地示例（交给研发与详情页的硬标尺） | 买家可感知验证方式 |
|--------------|----------------|--------------------------------------|------------------|
| 「用料扎实 / 质感厚重」 | 单位克重、厚度公差、纯度/支数 | 260g/㎡ 索罗娜混纺（公差 ±5g）、316L 不锈钢内胆壁厚 ≥ 0.8mm | 电子秤实测称重、卡尺微距实拍 |
| 「极致丝滑 / 细腻好吸收」 | 粒径区间、表面粗糙度、摩擦系数 | 粉体粒径 D90 ≤ 15μm、表面粗糙度 Ra ≤ 0.2μm | 9 倍微距镜头对比、水溶扩散计时 |
| 「经久耐用 / 不易变形」 | 疲劳测试循环次数、色牢度等级 | 领口螺纹经受 50 次标准机洗拉伸回弹率 ≥ 95%、耐摩擦色牢度 ≥ 4 级 | 实验室水洗编号对比图、暴力拉扯实测 |
| 「快速响应 / 售后无忧」 | 响应秒数、极速赔付/换新时效 | 人工客服 30 秒内接起、签收破损 2 小时内免寄回闪赔 | 订单后台服务承诺卡、超时自动触发赔付 |

**合规红线：** 量化标准须具备真实检测或履约依据，禁止虚标材质参数，不得在量产批次暗降规格掺水或以次充好。

```markdown
## 差异化策略选择

**选定路径：** {路径名}

**理由：**
1. 竞品在这个维度的弱点：{具体}
2. 我方具备的优势/资源：{具体}
3. 用户是否真的在乎这个差异：{验证逻辑}

**一句话差异化定位：**
"{产品名}是唯一一个 {差异化点} 的 {品类}，专为 {人群} 设计"
```

### 产品自传播设计：三态买家传播动机拆解表

产品本身能不能成为用户自发传播的理由，取决于是否针对不同关系深度的受众分别设计了可低阻力转发的钩子：

- **开箱 moment**：包装设计是否值得拍照分享？有没有"第一次看到就想发帖"的元素？
- **使用 before/after**：效果是否足够可视化？能不能 15 秒内展示？
- **彩蛋设计**：有没有意外惊喜（隐藏设计/手写卡/定制元素）？
- **品牌语言**：产品包装/说明上的文字，是否有传播性（值得被截图分享的金句）？

| 受众状态 | 核心心理诉求 | 产品内嵌传播载体与设计动作 | 触发动作与转化抓手 |
|---------|------------|------------------------|------------------|
| **1. 给围观受众（未购破圈层）** | 猎奇共鸣、有用避坑、情绪代偿 | **公共情绪议题**（包装/吊牌直击打工、失眠、社交内耗痛点）、**零门槛避坑干货**（随附行业选材鉴别卡）、**无伤大雅的品牌自嘲梗** | 截图发群讨论、收藏干货顺带记住品牌 |
| **2. 给已购顾客（去耻感晒单层 — 社交借口 Social Alibi）** | 体面表达、消除炫耀感或寒酸感 | 为买家设计能体面说圆消费动机的谈资（把「图便宜/跟风/纯功能刚需」转化为「审美先锋/理性反溢价/内行选材眼光/利他安利」），并在器型、特种开箱卡或批次铭牌上预留**实物拍照锚点** | 随手拍开箱/桌面一角发朋友圈或小红书，配文自然不违和 |
| **3. 给铁杆粉丝（深度共创层）** | 圈层身份认同、排他特权、被品牌重视 | **新品命名/配色投票权**、首批次**内测编号铭牌**（如 `#0042`）、老客才懂的**圈层专属暗号**与隐藏款兑换通道 | 主动在社群晒编号、拉同好入坑、参与新品评测 |

**合规红线：** 禁止使用合体红包、助力砍价、分享解锁等微信外链诱导分享手段，不得以返现或积分利诱指定好评晒单。

## 模块 5：产品命名与包装方向

名字和包装是产品在货架（线上/线下）上的第一个"广告位"。

> 实体品包装方向：特种包材、封印件、高感知伴手物与成本护栏见 `references/physical-craft-premium.md` §3；辅料成本不得侵蚀目标毛利率底线。

### 产品命名原则

**好名字的标准：**
- **好念好记**：读起来顺口，听一遍能记住
- **有意象**：让人联想到产品的核心特质或使用感受
- **有延展性**：可以成为系列（不会因为延伸新品而显得奇怪）
- **无歧义/无雷区**：在目标市场没有负面含义（特别注意跨语言市场）
- **可注册**：商标和域名是否可用

**命名方向参考：**

| 方向 | 逻辑 | 示例风格 |
|------|------|---------|
| 成分/原料命名 | 强化成分可信度 | 玻尿酸精华、角鲨烷面霜 |
| 功效命名 | 直接说结果 | 28天焕白、睡眠修护 |
| 情绪/场景命名 | 卖生活方式 | 晨间仪式感、城市游牧 |
| 人群命名 | 身份认同锚定 | 为跑者设计、职场女性的 XX |
| 地域/原产地命名 | 借地理背书 | 云南山茶花、北海道胶原蛋白 |
| 造词命名 | 品牌专属记忆点 | 需要声音/视觉双维度设计 |

### 命名工作流（先量后筛，不要直接端出三个名字）

命名最常见的失败不是"想不出好名字"，是**候选池太小**——只想了 5 个就挑出 1 个，挑出来的必然是这 5 个里最不差的，不是好的。

1. **内部先生成 30-50 个候选**，覆盖上表全部 6 个方向（每个方向至少 5 个），这一步不评判、不筛选，量先够。
2. **过反面清单**，命中任一条直接淘汰，不进入打分：
   - 与同品类现有品牌读音或字形近似（跟风感，且商标风险高）
   - 需要解释才能懂（名字自己不会说话，后续每一次传播都要额外付解释成本）
   - 生僻字、易读错、易打错（影响搜索和口碑传播）
   - 强行谐音梗（短期有趣，三个月后过时，且难以延伸成系列）
   - 把功效写死（如"三天白"）——后续延伸新品或遇到广告法功效审查会被卡死，与 mc-review 的合规硬门禁直接冲突
3. **对存活候选逐个打分**（下表），只有 ≥70 分的才有资格进入交付。
4. **回炉条件**：存活并达到 70 分的候选 **<3 个** → 回到第 1 步重新生成，不要降低标准硬凑三个。这是硬规则，不是建议。
5. 最终只呈现 3-5 个给用户，附完整打分——不要把 30 个候选全倒出来让用户自己挑，那是把工作退回给用户。

### 命名评分表（满分 100，<70 淘汰）

| 维度 | 分值 | 评分标准 |
|------|------|---------|
| **好念好记** | 25 | 念一遍能复述 = 20-25；念两遍能记住 = 12-19；需要看着字才能念 = <12。中文名超过 4 字、英文超过 3 音节的先扣分 |
| **意象贴合** | 25 | 名字唤起的联想与产品核心特质一致 = 20-25；中性无联想 = 12-19；联想跑偏或与定位冲突 = <12 |
| **延展性** | 20 | 可自然延伸出系列/子品类 = 16-20；勉强可延伸 = 10-15；写死在单一品类或单一功效 = <10 |
| **无雷区** | 20 | 目标市场无负面含义、无宗教/政治敏感、无谐音风险 = 16-20；有轻微歧义但可控 = 10-15；任一目标语言有负面含义 = 0（直接淘汰） |
| **可注册性** | 10 | 商标类目初查无近似 + 域名可得 = 8-10；商标可能有近似需专业检索 = 4-7；已知被占用 = 0 |

**打分纪律：**
- 「无雷区」得 0 或「可注册性」得 0 = 直接淘汰，不看总分——名字再好，注册不下来或在目标市场有负面含义都等于不能用。
- 出海产品必须逐个目标语言过「无雷区」，不能只查英文。
- 可注册性这一栏在没有专业商标检索工具时只能给出**初判**，必须标注 `（初判，需专业检索确认）`——这一栏的分数不构成法律意见。

## 模块 6：产品线架构

单品打爆之后，怎么延伸产品线？

> 非标高溢价实体品的产品线角色（话题钩子款 / 同器型材质分档款 / 高玩高定锚点款）及退货率前置干预见 `references/physical-craft-premium.md` §4。
> 延伸新品的品牌署名层级见 `mc-brand` 模块 6（及其品牌架构扩展矩阵）：单品验证期至细分品牌期（L1–L2）同人群延伸**默认采用「主品牌 + 增强型描述词」**，禁止盲目另造子品牌名拆散搜索词；低价防守跑量款须按比价隔离规则走独立副牌；已在模块 2 完成「品类量化立规」的自研配方/工艺/结构，优先评估提炼**要素品牌（Ingredient Branding）**跨 SKU 复用。

### 产品线规划框架

**水平延伸（Same Need, Different Variant）**
针对同一需求，提供不同规格/成分/场景的变体：
- 规格延伸：大包装/小包装/试用装/旅行装
- 成分变体：适合不同肤质/人群的版本
- 场景变体：日用款/夜用款/旅行款/礼品款

**垂直延伸（Same User, Adjacent Need）**
同一批用户，从一个需求延伸到相邻需求：
- 功效延伸：从补水延伸到提亮/抗老
- 步骤延伸：从精华延伸到配套的水/乳/霜

**价格带延伸（Entry / Core / Premium）**
- 入门款：降低试用门槛，拓宽用户池
- 主力款：最大化销量和利润
- 旗舰款：建立品牌高度，树立品牌价值锚点

```markdown
## 产品线架构规划

### 当前阶段：{单品验证期 / 产品线扩张期 / 品牌化阶段}

### 产品矩阵
| SKU | 定位 | 目标用户 | 售价 | 优先级 | 推出时间 |
|-----|------|---------|------|--------|---------|
| {主打单品} | 爆款打流量 | | | P0 | 立即 |
| {延伸品 1} | | | | P1 | Q+1 |
| {延伸品 2} | | | | P2 | Q+2 |

### SKU 扩张逻辑
{描述延伸的战略意图，不是为了有更多产品，而是为了 {具体商业目的}}
```

### 「木马钩子 × 后手利润池」跨 SKU 交叉补贴单元经济表

单靠单一爆款硬扛公域投放成本极易陷入亏损泥潭。规划产品线时，必须算清**入口钩子品（木马钩子）**与**后手利润池**之间的跨 SKU 交叉补贴账，明确谁负责低阻力破门获客、谁负责在复购周期内收回毛利：

| 角色维度 | 入口钩子品（木马钩子 SKU） | 后手利润品（利润池 SKU 矩阵） | 跨 SKU 单元经济核算护栏 |
|---------|--------------------------|-----------------------------|----------------------|
| **品类形态与特征** | 高频刚需、强体感痛点、低决策门槛（体验装/基础款/引流耗材） | 专用耗材、替换装、进阶配件、高毛利礼盒组合、周期续费服务 | 钩子品与利润品须具备强使用绑定或场景自然递进关系 |
| **定价与毛利策略** | 允许贴近BOM+履约成本获客，设定明确**单客获客让利上限（¥{X}/客）** | 维持健康高毛利（目标毛利率 ≥ {Y}%），承担全盘利润回收 | 禁止无后手承接的纯亏本冲量，防止羊毛党买完即走 |
| **核心转化与核算指标** | 首单转化率（CVR）、新客破冰成本（CAC） | **连带率 / 二购转化率（≥ {Z}%）**、单客回收毛利额、**`N` 天回本周期红线（≤ {N} 天）** | `单客让利额 + 首单投放费 ≤ 后手利润品在 N 天内的期望贡献毛利（连带率 × 后手毛利额）` |

**核算纪律与风险警示：** 若用户未提供真实毛利与复购数据，表中所有测算数字必须强制标注 `[假设]`，并输出**断链亏损警示**（提示若连带率低于临界值 `{Z_min}%` 或超过 `{N}` 天回本周期红线，前端放量越大亏损越剧烈，须先小步内测连带转化率再放大投放）。
