# 合规审查 — 中国市场

> last_verified: 2026-09-25 · 复核周期 180 天（CI 每周检查，超期报警）
> 审查参考，不构成法律意见；上线前由具备资质的法务复核。平台规则变动频繁，以平台最新公告为准。

## 法律法规高危项

| 检查项 | 风险 | 说明 | 依据 |
|--------|------|------|------|
| 绝对化用语 | 高 | 禁用"国家级""最高级""最佳"等用语；"第一""唯一""全网最低"等同类最高级表述同样高风险，须有可证明事实且避免绝对化 | 广告法第九条第（三）项 [1] |
| 疾病治疗功能 / 医疗用语 | 高 | 医疗、药品、医疗器械以外的广告不得涉及疾病治疗功能，不得使用医疗用语或易与药品、医疗器械混淆的用语 | 广告法第十七条 [1] |
| 化妆品功效 | 高 | 不得明示或暗示医疗作用（如抗炎、消炎、抑菌、祛疤、生发、溶脂、瘦身）；普通化妆品不得宣称特殊化妆品功效；美白、祛斑、防晒、防脱发属特殊化妆品，须注册且功效宣称有评价依据 | 化妆品监督管理条例第二十二条、第四十三条 [2]；北京市化妆品广告发布指引 [3] |
| 引证数据与出处 | 高 | 数据、统计资料、调查结果、文摘、引用语须真实准确并标明出处；有适用范围和有效期的须明确表示。编造机构、调研或样本量属虚假广告 | 广告法第十一条、第二十八条 [1] |
| 贬低竞品 | 中 | 不得贬低其他生产经营者的商品或服务 | 广告法第十三条 [1] |
| 划线价 / 价格比较 | 高 | 未标明被比较价格详情时，被比较价格不得高于前七日内最低成交价；不得临时抬价后打折，不得用无依据的价格作折扣基准；虚假折价、虚假价格比较属价格欺诈 | 明码标价和禁止价格欺诈规定第十六、十七、十九条 [4] |
| 虚假评价 / 好评返现 | 高 | 不得编造用户评价、隐匿差评或将好评前置；不得以返现、红包、卡券等利诱用户作出指定好评、点赞；不得组织虚假交易、虚假评价帮助他人宣传 | 网络反不正当竞争暂行规定第九条（2024-09-01 起）[5]；反不正当竞争法（2025 修订，2025-10-15 起）第九条 [6] |
| 广告可识别性 | 高 | 互联网广告须能让消费者辨明是广告；以知识介绍、体验分享、消费测评等形式推销并附购物链接的，须显著标明"广告"；竞价排名须标"广告" | 互联网广告管理办法第九条 [7] |
| 直播带货 | 高 | 不得对性能、销售情况、用户评价、荣誉资质等作虚假或引人误解的宣传；价格比较、折价须显著标明被比较价格或计算基准；不得虚构或篡改交易、关注度、浏览量、点赞量等数据 | 直播电商监督管理办法第三十二、三十四条（2026-02-01 起）[8]；网络直播营销管理办法（试行）第十八条 [9] |
| AI 生成内容 | 高 | AI 生成合成内容须加显式与隐式标识；AI 生成的人物形象直播带货须持续提示。细则见 `ai-content.md` | 人工智能生成合成内容标识办法（2025-09-01 起）[10]；直播电商监督管理办法第三十七条 [8] |

## 国内平台规则

| 平台 | 高频违规项 | 依据 |
|------|-----------|------|
| 小红书 | 在笔记、评论、私信、直播、置顶、包裹卡等场景传播联系方式、二维码、其他平台链接或店铺，或以"私信领优惠""加好友享折扣"暗示站外交易 → 警告、限流直至封号 | 《交易导流违规管理细则》（2025-03-12 起，据媒体报道）[11] |
| 抖音 | 发布第三方信息、诱导站外交易（微信号、二维码卡片、其他平台标识等）→ 商品下架、关闭电商权限、停业整顿、清退 | 抖音电商专项治理公告（2022-04，据媒体报道）[12] |
| 微信 | 以红包、优惠券、积分等利益，或助力、砍价、集赞、集卡等方式诱导分享外链；"分享后才能继续" → 限制链接传播、封禁分享接口 | 微信外部链接内容管理规范第 2.1 条 [13] |
| 微博 / B站 / 其他 | 商业推广（恰饭）未标识"广告"：不只是社区观感问题，同时构成法律风险 | 互联网广告管理办法第九条 [7] |
