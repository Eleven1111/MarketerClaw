# 敏感品类额外检查

> last_verified: 2026-09-25 · 复核周期 180 天（CI 每周检查，超期报警）
> 内容涉及以下品类时，无论法域一律追加加载本文件；各法域细则仍以对应 `compliance-*.md` 为准。

| 品类 | 国内规则 | 海外规则 | 依据 |
|------|---------|---------|------|
| 食品 | 不得涉及疾病治疗功能，不得使用医疗用语 | 泰国：宣传食品功效的广告须经 FDA 事先批准；英国："不太健康"食品付费在线广告全面禁止（见 `compliance-uk.md`） | 广告法第十七条 [1]；Thai FDA [5]；ASA/CAP LHF [6] |
| 保健食品 / 膳食补充剂 | 不得断言或保证功效与安全、不得涉及疾病预防治疗、不得暗示为健康所必需、不得与药品或其他保健食品比较、不得用代言人推荐；须显著标明"本品不能代替药物"；包装警示用语为"保健食品不是药物，不能代替药物治疗疾病" | 美国：结构/功能声明须附 FDA 标准免责声明，并在上市后 30 日内通知 FDA；涉及疾病声明即按药品监管 | 广告法第十八条 [1]；保健食品标注警示用语指南 [2]；21 CFR 101.93 [3] |
| 化妆品 | 见 `compliance-cn.md`「化妆品功效」 | 日本限 56 项效能；韩国功能性表述须审查或报告；新加坡不得宣称治疗作用 | 见各法域文件 [1] |
| 教育培训 | 不得对升学、考试、学位证书或培训效果作保证性承诺；不得暗示考试机构或命题人员参与；不得用科研单位、学术机构、专业人士、受益者名义推荐 | 美国：赚钱机会、课程收益类声明不得虚假或无依据 | 广告法第二十四条 [1]；FTC 赚钱机会处罚要约通知 [4] |
| 投资理财 | 须合理提示风险；不得保证收益、保本、无风险；不得用学术机构、专业人士、受益者名义推荐 | 英国：社交媒体金融推广须公平清晰；未经授权的网红推广可能构成刑事犯罪 | 广告法第二十五条 [1]；FCA FG24/1 [7] |
| 酒类 | 不得诱导、怂恿饮酒或宣传无节制饮酒；不得出现饮酒动作；不得表现驾驶等活动；不得暗示饮酒能消除紧张焦虑、增加体力 | 英国：饮酒者不得是或看起来未满 25 岁；受众中未满 18 岁者超过 25% 的媒体不得投放 | 广告法第二十三条 [1]；CAP Code 第 18 节 [8] |
| 儿童 / 未成年人 | 针对未成年人的大众传播媒介不得发布医疗、药品、保健食品、医疗器械、化妆品、酒类、美容广告；不满十周岁的未成年人不得作广告代言人 | 美国：COPPA（2025 修订，合规期限 2026-04-22 已过）；欧盟：GDPR 第 8 条（面向儿童的信息社会服务的同意年龄） | 广告法第三十八、四十条 [1]；16 CFR 312 [9]；GDPR [10] |
