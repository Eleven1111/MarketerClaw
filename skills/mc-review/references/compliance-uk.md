# 合规审查 — 英国市场 (ASA/CAP · CMA · FCA)

> last_verified: 2026-09-25 · 复核周期 180 天（CI 每周检查，超期报警）
> 审查参考，不构成法律意见；上线前由英国执业律师复核。

| 检查项 | 风险 | 说明 | 依据 |
|--------|------|------|------|
| 广告可识别 | 高 | 营销传播必须显而易见是广告；网红内容至少应在开头显著标 "Ad"；"gifted""PR trip""affiliate" 等标签不足以说明商业性质；平台 Paid partnership 标签单独使用可能不够；每条内容都要单独标注 | CAP Code 2.1、2.3 [1]；ASA/CMA 网红指南 [2] |
| 误导与证据 | 高 | 不得误导；可客观核实的声明在发布前须持有证据 | CAP Code 第 3 节（3.1、3.7）[3] |
| 虚假评价 | 高 | 撰写、委托虚假评价，发布隐瞒激励的评价，压制差评或只挑好评，均属一律禁止的行为；发布评价的一方须采取合理措施防止 | DMCC Act 2024 附表 20 第 13 段 [4]；CMA208 虚假评价指南 [5] |
| 价格与滴漏定价 | 高 | 可预见的强制性费用（服务费、订票费等）须计入首次展示的价格 | DMCC Act 2024 [4] |
| 执法后果 | 信息 | 2025-04-06 起，CMA 可直接认定违法，最高罚款全球年营业额 10% | DMCC Act 2024 [4] |
| 不太健康食品（LHF / HFSS） | 高 | 2026-01-05 起：付费在线广告全面禁止；电视和受 Ofcom 监管的点播服务 05:30-21:00 禁播；仅适用于属于 13 类且可被识别的 HFSS 产品 | ASA/CAP：LHF 新规与指南 [6] |
| 酒类 | 高 | 饮酒或担任重要角色的人不得是或看起来未满 25 岁；受众中未满 18 岁者超过 25% 的媒体不得投放 | CAP Code 18.15、18.16 [7] |
| 金融推广 | 高 | 社交媒体金融推广须公平、清晰、不误导；未经授权的网红推广受监管金融产品可能构成刑事犯罪，品牌须监控合作方 | FCA FG24/1 [8] |

**待核实（未写入上表，不作审查结论）**：食品营养/健康声明须在 GB NHC 注册表内；面向消费者的价格须含 VAT。
