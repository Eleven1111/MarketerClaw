# 负面→危机分流与过失×声量处置矩阵（mc-diagnose 按需加载）

> 加载时机：🚨 PR 危机模式触发，或用户拿着一条差评 / 一篇负面帖 / 一段群聊截图问“要不要发声明”时读取。
> 日常八维诊断不加载本文件。舆情数据由 `mc-monitor` 的 `Mode B：品牌舆情与危机流速监控` 提供，本文件只负责判断与处置。

## 一、负面→危机三级前置分流门禁（外松内紧原则）

**为什么先分流**：负面 ≠ 危机。对一条低转发的无稽之谈发官方声明，等于替它买了一次全量曝光——原本几百人看过的帖子，被官方回应带进了几十万人的视野（逆火 / 越描越黑效应）。所以每一条负面都先过门禁，再决定是否“出声”。

**外松内紧**：对外克制、不轻易表态；对内立即求证、备好口径、盯住数据。外松不是不管，内紧不是对外喊话。

### Tier 1：荒诞低量噪音

| 判定特征 | 处置动作 | 禁止动作 |
|---------|---------|---------|
| 普通账号发布、转评赞低、内容明显违背常识（无图无据的离谱指控、玩梗式造谣） | 静默留档：截图 + 链接 + 时间戳归档，进入观察名单 | 禁止官方公开回应或辟谣，不得在官方账号点名回击喂流量 |
| 未出现第二个独立信源 | 每日例行复查一次，命中升格信号即转 Tier 3 | 不得私下联系发帖人施压删帖 |

### Tier 2：低量真实个案投诉 / 流言

| 判定特征 | 处置动作 | 禁止动作 |
|---------|---------|---------|
| 有具体订单、具体经历的个案投诉，或局部社群内流传的半真半假说法 | ① 1v1 客服 / 私信闭环止血：主动联系当事人，登记诉求，给出明确处理时点 | 不得在公开评论区与投诉者争辩 |
| 传播仍停留在当事人及其小圈子 | ② 内部求证事实：调取批次、订单、聊天记录，备好口径**引而不发** | 不得在事实未明前发全网声明 |
| 尚未命中任何升格信号 | ③ 启动 `mc-monitor` Mode B 暗中盯盘，设定流速阈值告警 | 不得用赠品换删帖或要求当事人公开改口 |

**Tier 2 的成败标准**：当事人问题被解决、且不再继续发帖，即为闭环。闭环后把个案原因同步给产品 / 售后，避免同类投诉复现。

### Tier 3：危机升格信号（命中任一即进入危机响应）

| # | 升格信号 | 典型观测口径 |
|---|---------|-------------|
| ① | 权威媒体 / 政务号首发 | 主流媒体、监管部门、地方政务账号发布或转载 |
| ② | 头部达人转发破圈 | 粉丝量级远超品牌自身的账号参与转发或二创 |
| ③ | 单位时间转发 / 评论流速激增 | 小时级互动量较前一时段成倍放大，且未见衰减 |
| ④ | 评论区一边倒谴责 | 抽样评论中替品牌说话的声音几乎消失 |
| ⑤ | 同类投诉连续复现 | 不同账号、不同地区出现同一问题描述 |
| ⑥ | 涉及人身 / 食安 / 未成年人 / 宠物安全或公共利益 | 一旦涉及，不论声量大小直接升格 |
| ⑦ | 牵涉高管公开言行 | 创始人、高管的发言、直播片段、旧帖被翻出 |
| ⑧ | 内部敏感信息 / 聊天记录外泄 | 内部群截图、邮件、制度文件在外部流传 |
| ⑨ | 冲上平台热搜 / 热榜 | 任一主流平台热搜、热榜、同城榜上榜 |
| ⑩ | 包含 ≥2 种公众高敏情绪叠加 | 对照 `mc-monitor` Mode B 的 5 类公众高敏情绪叠加雷达 |

进入 Tier 3 后：先执行 `mc-diagnose/SKILL.md` 中「危机前线四道止血闸门与分级发言收口协议」，再用下方 2×2 矩阵定位象限、选择发声策略。

## 二、过失×声量 2×2 四象限博弈处置矩阵

先回答两个问题，再落象限：

- **过失轴**：按事实与规则，我方是否存在过失？在“于理”之外，公众朴素情感上是否认为我方有错（于情）？
- **声量轴**：当前传播是否仍可控（局限在少量账号与圈层），还是已经破圈？

```
                  声量可控                 声量巨大
              ┌───────────────────┬───────────────────┐
  于理无过失  │ 象限Ⅰ 冷处理定力    │ 象限Ⅱ 同理 + 核实   │
              ├───────────────────┼───────────────────┤
  于情有争议  │ 象限Ⅲ 先合情、再合理（不论声量大小）       │
              ├───────────────────┴───────────────────┤
  于理于情有过失│ 象限Ⅳ 魔鬼代言人 + 赔付 + 锁界致歉 + 转换故事 │
              └───────────────────────────────────────┘
```

### 象限Ⅰ：于理无过失 + 声量可控（如被外部事件关联躺枪）

- 保持定力冷处理：不主动发声明，不蹭热度自证清白。
- 备好事实说明（时间线 + 证据 + 一句话结论），仅在媒体或合作方问询时点对点同步。
- 持续用 `mc-monitor` Mode B 观察，一旦声量越过阈值即转入象限Ⅱ。

### 象限Ⅱ：于理无过失 + 声量巨大（如大规模谣言 / 误伤）

- **表达同理关切而非愤怒控诉**：先承认公众担心是合理的，再给事实。
- **业务沟通人点对点核实**：由熟悉业务的自有沟通人直接联系首发者核实信息来源，禁止外包代理机构代劳，避免口径走样。
- **联动权威第三方 / 科普信源拆解事实**：检测机构、行业协会、专业科普作者的独立说明，比品牌自说自话更可信。
- **定时同步排查心跳**：公布下次通报时间，并按时更新进展，即使进展只是“仍在排查”。
- **禁止在声明中复述谣言原话帮其二次扩音**：只陈述事实与结论，不引用谣言原句、不放谣言截图。
- **禁止在舆情早期向普通消费者 / 网友发律师函威胁**：针对有组织的黑产造谣，固定证据链后静默走司法程序；不得拿空头法务威胁当公关挡箭牌。

### 象限Ⅲ：于理无过失但于情有争议（如合规但反人性的规则 / 职场争议 / 算法体感冲突）

**「先合情、再合理」铁律**：

- 禁止甩出冰冷法条、质检合格证或行业黑话硬怼消费者体感——“我们完全合规”在这个象限里等于火上浇油。
- 先以「一个好人这时该怎么做」对齐朴素同理心，表达关切与理解。
- 再说明事实依据，并给出具体改进动作与生效时间（规则调整、补偿方案、机制优化）。
- 自检一句话：把声明念给一位不懂行的家人听，对方第一反应是“他们懂我”还是“他们在讲理”？后者需重写。

### 象限Ⅳ：于理于情均存在过失

1. **「外部舆论魔鬼代言人」**：内部公关负责站在最挑剔的外部视角发问，阻断管理层“先瞒一瞒”的侥幸心理。二次公关的成本远高于一次诚意买单——被扒出来的隐瞒会把单点事故变成信任崩塌。
2. **一线免 KPI 扣罚快速赔付授权池**：提前给门店、客服、私域一线授予额度内的快速赔付权，且该笔赔付不计入个人 KPI 扣罚；在线下 / 私域黄金窗口先把受损个体赔到位，防止个案维权升级成公共事件。
3. **「锁界致歉」法则**：精确锁定问题批次 / 门店 / 环节与整改时点（“X 月 X 日 X 批次 / X 门店 / X 工序”），禁止甩锅“行业惯例 / 临时工 / 供应商”；也不得做未经核实的全局大包大揽（“我们所有产品都有问题”会制造新的恐慌）。
4. **死局「转换故事」机制**：陷入单点口水战死胡同时，主动开放透明工厂直播、组建用户监督团、推动行业标准升级，把“品牌 vs 受害者”的对抗叙事切换为“品牌 + 用户”的共建叙事。

## 三、四象限速查与路由

| 象限 | 一句话策略 | 首要动作 | 对接技能 |
|------|-----------|---------|---------|
| Ⅰ | 冷处理定力 | 备好事实说明，问询时点对点同步 | mc-monitor（Mode B 盯盘） |
| Ⅱ | 同理关切 + 第三方拆解 | 业务沟通人核实首发者 + 定时心跳通报 | mc-monitor → mc-review → mc-content |
| Ⅲ | 先合情、再合理 | 先共情表态，再讲事实与改进 | mc-copy → mc-review |
| Ⅳ | 认错到位 + 锁界致歉 | 快速赔付 + 锁定批次的致歉声明 | mc-community → mc-copy → mc-review |

所有对外声明发布前必须过 `mc-review` 的「危机声明反次生灾害 7 项否决检视」。

## 四、合规底线（全象限通用）

- 禁止有偿删帖、付费撤稿或花钱撤热搜等非法交易；不得删帖压热搜掩盖事实。
- 不得雇佣水军控评或找水军洗地。
- 禁止制造供不应求假象转移视线；不得伪造第三方检测报告或权威背书。
- 线下维权现场不得强行架离当事人或抢夺其拍摄设备，由门店负责人到场倾听并登记诉求。
- 澄清内容禁止隐蔽软植不标广告：借澄清带货或植入推广的，须按《互联网广告管理办法》显著标明“广告”。
